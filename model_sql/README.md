## 📋 数据集结构

导入后会创建：

```
股票数据分析（数据集）
├── 模型
│   ├── 股票日线数据（12个字段）
│   │   └── 交易日期、股票代码、开盘价、收盘价、涨跌幅、成交量等
│   └── 股票基本信息（5个字段）
│       └── 股票代码、股票名称、所属行业、市场、状态
│
└── 指标（7个）
    ├── 最大涨幅 = MAX(涨跌幅)
    ├── 最小涨幅 = MIN(涨跌幅)
    ├── 平均涨跌幅 = AVG(涨跌幅)
    ├── 累计涨跌幅 = SUM(涨跌幅)
    ├── 总成交量 = SUM(成交量)
    ├── 总成交额 = SUM(成交额)
    └── 平均换手率 = AVG(换手率)
```

## ⚠️ 注意事项

1. **数据库选择**：导入时必须选择正确的数据库（stocks_data）
2. **模型SQL**：使用简单的单表查询，避免复杂的 JOIN 和函数
3. **删除顺序**：系统已支持级联删除，直接删除模型即可
